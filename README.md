# P&S Potable Water

Website for P&S Potable Water Tankers & Potable Water Delivery.

## Netlify

This is a static HTML/CSS/JS site. Publish the repository through the `pands-potable-water` Netlify project. The enquiry form is configured for Netlify Forms.

Before launch, replace the placeholder phone number and email address in `index.html` with the confirmed business contact details.
